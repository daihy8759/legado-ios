# 远端存储

入口：**我的 → 远端存储**，或「文件管理 / 其他设置 → 远端存储」。

支持多份存储配置、连接测试、逐级目录浏览、新建文件夹、上传文件和下载到系统「文件」。TXT / EPUB 还可以选择「下载并加入书架」，保存为本机副本后沿用现有阅读功能。也支持通过同一存储同步各设备的书架、分组和阅读进度。

## 书架与阅读进度同步

1. 在每台设备添加指向**同一账号、同一目录 / Bucket 前缀**的远端存储。
2. 在页面顶部「书架与阅读进度 → 同步存储」中选中该配置。自动同步默认开启；也可关闭后使用「立即同步」。
3. 等待显示同步完成，再在另一台设备同步并打开书籍。书源配置也随同步传输；需要登录的网站仍需在各设备单独登录。

| 数据 | 同步行为 |
| --- | --- |
| 书架 | 合并书籍、排序、书籍资料和自定义分组；同一网络书按书籍 URL 识别 |
| 删除 | 删除记录传播到其他设备，旧的阅读进度不会将已删除的书重新加入书架；主动重新加入可以恢复 |
| 阅读进度 | 按最近阅读时间合并章节、章节内文字位置和 EPUB locator；主动回读的较小章节号也可成为最新位置 |
| 本地 TXT / EPUB | 同步原文件并校验 SHA-256；相同内容跨设备和改名后仍识别为同一本书，设备文件路径各自保留 |
| 书源与规则 | 书源、替换规则、TXT 目录规则、TTS、规则订阅与 RSS 源按记录合并，删除通过墓碑传播 |
| 书签、笔记与统计 | 同步书签、笔记及各设备阅读记录；本地书笔记通过文件摘要识别书籍并映射本机地址 |
| 本机数据 | 登录状态、Cookie、远端存储凭据、章节缓存和界面偏好不参与同步 |

自动同步在启动和回到前台时拉取合并，在书架、分组或进度变化后约 10 秒执行；持续阅读时会分批上传。退到后台时会立即尝试同步，并申请系统允许的短暂执行时间；大文件或慢网络可能无法在应用挂起前完成，回到前台后会重试。强制退出应用不能保证后台完成。可在「上次成功」和状态文字确认结果。

同步按书籍资料、阅读进度和加入 / 删除事件分别合并。进度使用设备记录的阅读时间；各设备应开启系统自动日期与时间。相同时间的并发修改按事件序号和设备标识稳定决胜。传输期间的本机阅读、添加和删除会保留，并在随后一次同步发送。

同步数据位于配置根目录下的 `LegadoSync/v1`：`files` 保存本地书原文件，`snapshots` 保存书架不可变快照；`sources`、`rules`、`bookmarks`、`stats`、`notes`、`configuration` 分别保存其他数据的不可变快照。每次读取各设备的最新快照，避免同时上传时互相覆盖；删除记录随快照保留。移出书架不会删除本地或远端原文件。历史快照和原文件目前不自动清理，请保留整个同步目录。旧版客户端仅同步书架，需升级后才能接收新增的数据类别。

## 整包备份

入口：**我的 → 设置 → 备份与恢复**。可以将 ZIP 存入系统“文件”，或选择已配置的 WebDAV / S3 / Dropbox，上传至 `LegadoBackups` 并从该目录选择备份恢复。恢复前显示数据清单，提供合并与覆盖两种方式。

备份包括书架、进度、分组、书源、规则、书签、笔记、阅读统计、RSS 源、TTS、规则订阅、网络设置、阅读偏好，以及书架上的本地 TXT / EPUB 原文件。恢复本地书时重写设备文件路径，并同步重写笔记中的书籍地址。单原文件上限 150 MB，解包总大小上限 512 MiB。登录态、Cookie、Keychain 凭据、自定义字体和背景图片文件不包含在备份中。

远端备份沿用存储客户端单文件 150 MB 的传输上限；超出时可使用本地“文件”导出。

恢复时数据库记录在同一事务内写入；规则文件与设置写入失败会尝试恢复原值。备份文件可自动识别 Android Legado 的常见 JSON 文件名，但 Android 专有字段、设备路径和不同版本格式仍需实际备份包验证。当前备份未加密，也未提供定时备份和自动清理。

只有远端传输和本机书架保存成功后才更新本机同步基线。网络、鉴权、校验或保存失败会显示错误并保留可重试状态；本地书文件缺失或超过 150 MB 时会中止该轮同步并提示书名。

## 配置

| 类型 | 必填字段 | 可选字段 |
| --- | --- | --- |
| WebDAV | 名称、已存在的目录 URL | 用户名、密码（公开目录可留空） |
| S3 / 兼容服务 | 名称、Endpoint、Region、Bucket、Access Key ID、Secret Access Key | Session Token、目录前缀、Path-style 开关 |
| Dropbox | 名称、Access Token | 根目录 |

WebDAV 推荐使用 HTTPS 和应用专用密码。根 URL 必须指向可列出内容的目录，例如 `https://example.com/dav/books/`。

S3 使用 AWS Signature Version 4，支持 AWS S3 及 MinIO 等兼容服务。填写服务商提供的完整 Endpoint 和 Region；AWS 示例为 `https://s3.us-east-1.amazonaws.com`、`us-east-1`。Path-style 默认开启，请求地址为 `Endpoint/Bucket/对象`；关闭后使用 `Bucket.Endpoint/对象`。目录前缀限定浏览位置，不需要预先创建目录标记。账号需要对目标前缀拥有列出对象、读取和写入权限；存储桶需预先创建。

Dropbox 使用用户自行创建的应用令牌。进入 [Dropbox 应用管理](https://www.dropbox.com/developers/apps)，启用 `files.metadata.read`、`files.content.read`、`files.content.write` 后生成对应的令牌。应用文件夹型应用只能浏览该应用的文件夹；根目录留空代表令牌可访问的根。当前不提供 OAuth 登录与令牌自动刷新，短期令牌过期后需编辑配置更新。

## 文件操作与凭据

- 单个文件上限 150 MB。上传遇到同名文件报错，保留原文件；可在本机重命名后重新上传。
- 目录列表自动读取 WebDAV Depth 1、S3 ListObjectsV2 和 Dropbox 分页结果。
- 下载到书架会复制到应用内本地书目录；选中同步存储后，阅读进度也会参与同步。
- 服务器名称和类型存入 SQLite，完整连接配置保存在系统钥匙串，并限定在本设备使用。旧 WebDAV 数据库配置可继续读取，下一次保存时迁移至钥匙串。
- 左滑或长按存储条目可编辑 / 移除配置。移除只影响本机，保留远端文件。
- 远端连接使用独立会话，验证 HTTPS 证书、不共用书源 Cookie 或请求日志、不跟随重定向。遇到 HTTP 3xx 时应将配置改为服务的最终地址。
- HTTP 地址会明文传输凭据与文件；应优先使用 HTTPS。

## 验证

`RemoteStorageTests` 使用自造响应和临时数据库，覆盖 AWS 官方 SigV4 签名示例、S3 / Dropbox 分页、WebDAV 多状态响应、中文及 emoji 路径、同名上传保护、认证失败、无效配置和钥匙串故障回滚。`BookshelfSyncTests` 和 `BookshelfSyncApplicationTests` 覆盖双设备合并、并发写入、删除与重新加入、回读和 EPUB 位置、分组编号映射、本地原文件及改名、失败重试、传输期间本机修改和保存失败。测试不连接个人远端账号。上线前可针对实际服务配置执行「测试连接」，再上传 / 下载一个小文件确认权限。

协议参考：[AWS SigV4 示例](https://docs.aws.amazon.com/AmazonS3/latest/developerguide/sig-v4-header-based-auth.html)、[Dropbox 官方 API 规范](https://github.com/dropbox/dropbox-api-spec/blob/main/files.stone)。
